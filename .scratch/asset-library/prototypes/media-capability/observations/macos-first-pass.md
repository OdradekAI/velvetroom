# macOS 媒体原型首轮观察

日期：2026-10-09（Asia/Shanghai，事件日志使用 UTC）。状态：**部分观察完成；媒体原型决策未关闭**。

实际产物为 Rust + Tauri `.app`，不是浏览器独立页面或 Eagle 的结果。通过桌面 UI 打开包，读取可见状态与截图，手动点击样本和控制。另有纯 HTML 模拟状态页，不能与真实操作的结果混用。

## 环境与可复现证据

- Apple M5 Pro、64 GiB、macOS 27.0.1 (26A434)、arm64；CLT SDK 26.5，Apple Swift 6.3.3。
- Rust 1.99.0；Tauri 2.12.1、tauri-build 2.7.1；系统 WebKit `22625.1.29.11.28`。实际依赖与链接清单见[构建环境](build-environment.json)。
- 自有 Swift helper 在应用包的 Resources 内运行，依赖路径均指向 Apple 系统 frameworks／`/usr/lib`，没有发现 Homebrew 或开发机自定义 dylib 路径。没有在无开发工具的另一台 Mac 验证，故不推导干净系统开箱可用。
- 最终本机包约 17.01 MiB；包含自制样本。最初包 strict signature 检查失败；补本地 ad-hoc 完整性签名后 `codesign --verify --deep --strict` 返回 0。未做 Developer ID、公证、安装器、自动升级或分发验收。
- helper 最初未显式 SDK 时无法加载 Swift 标准库；指定 CLT SDK 后编译通过。所有原件和包内对应文件的哈希均匹配清单：[34 项核对](original-hashes.json)，其中两项是预期缺失路径的 `null` 对照，实际文件哈希 32 项。
- 输出日志与尺寸保留于[组件任务记录](native-jobs.json)；进程输出目录属于原型缓存，未读取真实 Eagle 图库。

## 代理与取消的实际证据

5 秒 HEVC 经 AVFoundation 1280×720 preset 转为 H.264/AAC MP4，生成耗时约 232ms；输出 376,163 字节。Rust 收到成功结果后才发布路径，helper 检查输出视频轨及时长；真实 Tauri 窗口收到 loadeddata，播放／暂停／seeked，并观察中点画面。原件保持独立且哈希不变。本例输入本来就是 SDR，**没有证明 HDR→SDR 转换正确**。

较长样本生成约 0.7 秒后点击取消。实现向 helper 发强制结束并等待该进程退出，界面明确记为 `interrupted`；输出目录留下约 3,376,343 字节的部分 MP4，无成功 result.json，不发布为代理。随后新建 job 重试，耗时约 1,568ms，生成 8,899,761 字节文件；实际窗口可播放、暂停并定位约 60 秒。旧残留保留隔离，未覆盖或自动清理。

强制结束 helper 不等于 AVFoundation 导出任务通过正常取消路径返回；也未证明下游系统服务全部收束或立即安全清理。当前实验用新目录避免与旧输出复用，不能把此实现直接提升为已确认的产品取消／恢复契约。后续需补正常取消信号、完成竞争、未知结果核验与重启后记录。

## 流程模拟观察

通过 UI 完成六个引导场景：完整准备、取消代理、离线与旧内容、断开与继续、结果不明、读取时变更。观察到传输 100% 仍停在核验中；取消代理后已核验本地文件保留；重连不自动继续；旧 v1 代理不冒充 v2；未知结果时直接重试被拒；读取期间内容改变时保留待核验且不发布代理。

模拟页不读取磁盘，预计 120MB 是明确标注的例子。它不验证任何真实下载、恢复、原件版本识别、空间测量或 NAS 语义。用户体验反馈仍待回答，不代替用户确认。

## 时间、内存与边界

ImageIO HEIC 生成三次约 84.6、79.4、80ms；GIF 约 11.2ms，动画 WebP 约 7.9ms；两页 PDF 约 47.4ms；视频封面约 89.6ms。来源是 helper 自记录 wall time，未包含窗口交互和全部进程启动成本，也不是统计基准。操作系统缓存未控制，不能称为严格冷／热测试。

一次主 Rust 进程 RSS 为 113,792 KiB，不含 WebKit、GPU 和媒体服务，未记录峰值。因此整应用内存、启动延迟、取消延迟分布及性能门槛尚未完成。没有用 UI 工具调用耗时冒充应用启动时间。

## 未完成前置与继续位置

Windows 用户明确暂无环境，单独准备任务保持开放。HDR→SDR、图像方向／ICC、更多编解码变体、复杂动画／PDF、真实音频监听、正常取消／重启恢复、严格冷暖与内存测量、无开发环境机器、最低系统及发行验证仍未完成。保留首发 HEIC/HEVC 开箱可用要求，未因实验不足降低目标。

本机实验只支持“存在一条能实际跑通这些自制小样本的 macOS 路线”这一有限结论。没有裁定最终媒体后端、Swift 使用、React、SQLite 或整体模块边界。下一会话从媒体原型票 Progress 继续，先接用户反馈，再安排缺失样本及环境，不把本报告当全票 Answer。
